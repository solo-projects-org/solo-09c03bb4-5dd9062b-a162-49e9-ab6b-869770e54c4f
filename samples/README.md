# 跨段示例采样

这三个单列 CSV 由 `generate_samples.py` 用 NumPy 确定性生成（无需随机数），
采样率 256 Hz，总信号 1024 点（4 s）：

```
x[n] = 2.0·sin(2π·20·n/256) + 0.6·sin(2π·55·n/256 + 0.7) + 0.3·sin(2π·90·n/256)
```

| 文件 | 全局样点区间（半开） | 点数 | 说明 |
|---|---|---:|---|
| `demo_seg1_start0.csv` | `[0, 300)` | 300 | 段 A |
| `demo_seg2_start300.csv` | `[300, 650)` | 350 | 段 B，与 A 相邻；窗 1、2 跨 A/B |
| `demo_seg3_start700.csv` | `[700, 1024)` | 324 | 段 C；`[650,700)` 故意留 50 点缺口 |

每个文件首行是 `#` 开头的说明，上传时会被识别为表头跳过。

## 窗格结果（窗长 256、步长 128，自样点 0 起）

| 窗 | 样点区间（含端点） | 覆盖情况 | 是否在库 |
|---|---|---|---|
| 0 | `[0, 255]` | A 完整覆盖 | ✅ |
| 1 | `[128, 383]` | A+B 跨段拼成 | ✅ |
| 2 | `[256, 511]` | A+B 跨段拼成 | ✅ |
| 3 | `[384, 639]` | B 完整覆盖 | ✅ |
| 4 | `[512, 767]` | 缺 `[650,700)` | ❌ 撤下 |
| 5 | `[640, 895]` | 缺 `[650,700)` | ❌ 撤下 |
| 6 | `[768, 1023]` | C 完整覆盖 | ✅ |
| 7 | `[896, 1151]` | C 长度不足 | ❌ 未入库 |

## 网页试用路径

启动后点右上角 **「载入跨段示例」**（等价于
`POST /api/demo/load` 带 `{"reset": true}`），推荐核对：

- 时段 `0–1023`、频带 `15–25 Hz`：**5 个有效窗，平均带内均方 = 2.000000**
  （20 Hz 振幅 2.0，整周期采样，谱线无泄漏，均方恰为 A²/2）。
- 时段 `128–511`：**2 个跨段有效窗**（窗 1、2），均值同样 ≈ 2.0。
- 时段 `0–639`：**4 个有效窗**。
- 时段 `512–895`、任意频带：窗 4、5 完整落入但都残缺 → **缺测**。
- `50–60 Hz` 均值 ≈ 0.18；`85–95 Hz` 均值 ≈ 0.045；
  `0–128 Hz` 全频带均值 ≈ 2.225（= 信号时域均方，验证 Parseval）。

也可以手动按起始样点上传：

```bash
curl -F start_sample=0   -F file=@samples/demo_seg1_start0.csv   http://localhost:8000/api/segments
curl -F start_sample=300 -F file=@samples/demo_seg2_start300.csv  http://localhost:8000/api/segments
curl -F start_sample=700 -F file=@samples/demo_seg3_start700.csv   http://localhost:8000/api/segments
```

重新生成：

```bash
python3 samples/generate_samples.py
```
